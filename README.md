# Deutsch AI

## Project Description

Deutsch AI is a language learning application developed with Python.

## Current Features

- Vocabulary search
- Article training
- Error explanations
- Score calculation 
- Percentage calculation

## Technologies

- Python
- JSON
- Git/GitHub

## Project Structure

- `backend/` - Python application code
- `content/` - Learning content and vocabulary
- `docs/` - Project documentation
- `scripts/` - Utility scripts

## How to Run

Run the vocabulary search program from the project root directory:
```bash 
python backend/app/practice_day17.py
```
